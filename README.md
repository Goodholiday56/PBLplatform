# 人机共跑 — 跨学科 PBL 教学平台

以"2026 北京亦庄人形机器人半程马拉松"为真实情境的跨学科项目式学习平台。服务初三升高一学生，12 课时 × 4 模块，7 天学习周期。

## 四个模块

| 模块 | 名称 | 学科 | 内容 |
|------|------|------|------|
| M1 | 城市与产业 | 地理 · 政治 | 为什么赛事落地亦庄？地图定位、产业链分析、政策解读 |
| M2 | 科技与工程 | 物理 · 信息技术 | 机器人如何自主奔跑？系统拆解、五维评价、创新设计 |
| M3 | 数据与原理 | 数学 · 物理 | 如何优化完赛能力？数据分析、力学归因、策略设计 |
| M4 | 传播与表达 | 语文 · 英语 · 美术 | 如何讲好科技故事？新闻拆解、创作工坊、人机对比 |

## 技术栈

- **前端**：纯 HTML/CSS/JS，零外部 CDN 依赖
- **后端**：Node.js 原生 HTTP 服务
- **AI**：DeepSeek API（术语通俗化、文案润色、英文翻译、合规检查）
- **地图**：Leaflet + 高德瓦片
- **设计**：Material Design 3 风格

## 本地运行

```bash
# 1. 启动服务
node server.js

# 2. 浏览器打开
http://localhost:8000
```

首次启动自动创建默认账号：

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 教师 | `teacher` | `123456` |
| 学生 | `student` | `123456` |

教师账号可发布活动、管理班级；学生账号按教师发布的节奏逐活动学习。

## 项目结构

```
├── index.html          # 前端主文件（HTML + CSS + JS）
├── materials.js        # 教学资料数据（学习内容 + 学习活动）
├── server.js           # Node.js 后端（API + 静态服务）
├── lib/                # 本地库文件（Leaflet）
├── assets/             # 静态资源
├── data/               # 运行时数据（用户、进度、发布状态等，已 gitignore）
├── 平台教学资源/        # 教学配套文件（图片、文档、表格）
├── 项目背景.md          # 完整教学设计文档
└── PRD-人机共跑教学平台.md  # 产品需求文档
```
